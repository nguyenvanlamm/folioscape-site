# folioscape-site

Trang giới thiệu, chính sách quyền riêng tư và hỗ trợ của game Folioscape (iPhone), phục vụ bằng GitHub Pages từ nhánh
`main` (không dùng GitHub Actions).

- `index.html`: trang giới thiệu (tiếng Anh).
- `privacy.html`: Privacy Policy URL cho App Store Connect.
- `support.html`: Support URL cho App Store Connect.
- `assets/`: icon, ảnh màn chơi, font Young Serif và Figtree (OFL, giấy phép kèm theo trong `assets/fonts/`).

Mã game: https://github.com/nguyenvanlamm/folioscape
